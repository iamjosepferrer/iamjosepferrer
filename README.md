## What I've built

**[popgrid](https://github.com/databites-tech/popgrid)**: an open-source Python library for block cartograms where every block is an equal share of land, population or GDP. `pip install popgrid`, or [try the explorer in your browser](https://popgrid.databites.tech/).

<p align="center">
  <a href="https://github.com/databites-tech/popgrid"><img src="https://raw.githubusercontent.com/databites-tech/popgrid/main/docs/img/spain_compare.png" width="85%" alt="popgrid: land area vs population of Spain"></a>
</p>

Interactive data stories, all built on public data:

- **[Five ways to hear New York](https://five-ways-nyc.databites.tech/)**: 5.6 million NYC 311 noise complaints, drawn as five different maps.
- **[A forest in the grid](https://forest-in-the-grid.databites.tech/)**: Barcelona's 222,065 public trees, drawn one by one.
- **[After the lights came on](https://after-the-lights.databites.tech/)**: how electricity access changed the world since 2000.
- **[Catalonia Income Atlas](https://catalonia-atlas.databites.tech/)**: income inequality across 5,108 census tracts.

The full portfolio is at **[databites.tech/projects](https://databites.tech/projects)**, and the code lives in the **[databites-tech](https://github.com/databites-tech)** organisation.
